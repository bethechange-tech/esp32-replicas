# Security

Report a vulnerability through GitHub's private vulnerability reporting: open the repository's
Security tab and choose "Report a vulnerability". Do not report it in a public issue, a pull
request or a discussion.

Please include what you found, how to reproduce it and which version or commit you tested. We
will acknowledge the report, work on a fix in private and tell you when it is released.

This project runs other people's firmware inside an emulator. A way for a firmware image to
escape the emulator, read the host's files or reach the network beyond the names a run maps is
in scope.
